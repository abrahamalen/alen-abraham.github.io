Eyrie finds my other terminals

Until today Eyrie only knew about sessions it started itself. Most of my sessions don’t start there. I open a terminal tab and run claude or codex like always. So now the widget lists sessions running in my own terminals, and the Sessions page shows Claude Code and Codex sessions running outside Eyrie too. Also today: Release builds for the widget, as a .app and a .dmg . An app icon. A high-level LLD doc. Per-CLI locks, so two actions on the same CLI can’t step on each other. Wider secret masking in anything Eyrie shows or logs. Next up: Gemini CLI support and proper packaging, so someone other than me can install it.

Eyrie gets a new look, and Linux

Sunday was mostly about how Eyrie looks. I restyled the whole app in a new design language: paper and ink colours, small mono eyebrows over each section. What else got done: /api/v1/summary , one endpoint that feeds both the home page and the widget. A systemd user service, so it runs on Ubuntu the same way the launchd agent does on macOS. A platform matrix design: macOS, Ubuntu and Fedora for now. Windows is deferred. Started the top-bar widget in Tauri. Next up: getting the widget to show sessions that I started outside Eyrie.
