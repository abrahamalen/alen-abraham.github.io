---
title: "Eyrie finds my other terminals"
date: 2026-10-19
---

Until today Eyrie only knew about sessions it started itself. Most of my sessions don't start there. I open a terminal tab and run `claude` or `codex` like always.

So now the widget lists sessions running in my own terminals, and the Sessions page shows Claude Code and Codex sessions running outside Eyrie too.

Also today:

- Release builds for the widget, as a `.app` and a `.dmg`.
- An app icon.
- A high-level LLD doc.
- Per-CLI locks, so two actions on the same CLI can't step on each other.
- Wider secret masking in anything Eyrie shows or logs.

Next up: Gemini CLI support and proper packaging, so someone other than me can install it.
