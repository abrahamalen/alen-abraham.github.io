Started Eyrie today. It's my own open-source control plane for the AI coding CLIs I use every day (Claude Code, Codex, Gemini CLI), and it runs locally. The code is at [github.com/abrahamalen/eyrie](https://github.com/abrahamalen/eyrie).

The first design had Docker in it. I dropped that early. Everything Eyrie needs is already on my laptop: the CLIs, their config files, their transcripts. A container would only get in the way, so it's laptop-only.

Most of the day went into the FastAPI backend:

- Config and local-only security, so it only listens on my machine.
- A Usage page that indexes Claude Code transcripts and shows daily cost and tokens by model.
- An action layer for adding and removing MCP servers and toggling plugins. It runs through the CLIs' own commands, and every action lands in an audit log.
- A session manager that runs Claude Code and Codex inside Eyrie's own tmux server, with start, stop and resume.
- An in-browser terminal: tmux attach over a WebSocket pty, rendered with xterm.
- A memory editor, and task editing with conflict checks so I don't overwrite a change made somewhere else.
- Frontend types generated from the OpenAPI schema, CI, and `make install` to run it as a launchd agent.

I also made a clickable prototype, plus designs for a new home page and a small top-bar widget.

Next up: restyling the app to match the new designs, and starting the widget.
