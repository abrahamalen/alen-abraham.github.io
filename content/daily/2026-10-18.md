date: 2026-10-18

Sunday was mostly about how Eyrie looks. I restyled the whole app in a new design language: paper and ink colours, small mono eyebrows over each section.

What else got done:

- `/api/v1/summary`, one endpoint that feeds both the home page and the widget.
- A systemd user service, so it runs on Ubuntu the same way the launchd agent does on macOS.
- A platform matrix design: macOS, Ubuntu and Fedora for now. Windows is deferred.
- Started the top-bar widget in Tauri.

Next up: getting the widget to show sessions that I started outside Eyrie.
